
#  STREET SHOES

Aplicación web de comercio electrónico enfocada en la venta de sneakers, desarrollada con Python y Flask.

## Características

- Catálogo de productos.
- Navegación por marcas.
- Sección de ofertas.
- Carrito de compras.
- Actualización y eliminación de productos del carrito.
- Página de contacto.
- Interfaz web con HTML y CSS.

## Tecnologías utilizadas

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Git y GitHub
- Jinja2

## Instalación y ejecución

1. Clonar el repositorio:

```bash
git clone https://github.com/JuanGutierrezV/Street-Shoes.git
```

2. Entrar al proyecto:

```bash
cd Street-Shoes
```

3. Crear un entorno virtual:

```bash
python -m venv venv
```

4. Activar el entorno virtual en Windows:

```bash
venv\Scripts\activate
```

5. Instalar Flask:

```bash
pip install Flask
```

6. Ejecutar la aplicación:

```bash
python app.py
```

7. Abrir en el navegador:

```text
http://127.0.0.1:5000
```
